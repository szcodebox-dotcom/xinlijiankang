# 心联 · 区心理健康监测平台（演练版）

本地可运行的 **功能演练 Demo**，用于演示一人一档、预警工单、家校建议书签收、区/校/班看板与学生测评入口。  
**不是生产系统**：无真实登录鉴权、无数据库、无 Docker、无真实量表常模与加密算法。接口以内存 mock 模拟 `/api/v1` 行为。

品牌名：**心联**（区心理健康监测平台 · 演练版）

---

## 环境要求

| 项 | 要求 |
|----|------|
| Node.js | **≥ 18**（推荐 20 / 22 LTS） |
| 包管理 | npm（随 Node 附带） |
| 浏览器 | 现代桌面浏览器（Chrome / Edge / Firefox） |

不需要 Docker、数据库或其他外部服务。

---

## 本地启动

```bash
npm install
npm run dev
```

- 默认地址：<http://localhost:5173>
- 默认端口：**5173**（Vite）

其他命令：

```bash
npm run build    # 类型检查 + 生产构建 → dist/
npm run preview  # 预览构建产物（同样默认 5173）
```

一条命令起服务：`npm install && npm run dev`

---

## 技术说明

- **Vite + React 18 + TypeScript** 单仓前端
- **react-router-dom** 页面路由
- **内存 mock**（`src/mock/api.ts` + `src/data/seed.ts`），不启 json-server / 后端进程
- 右上角 **角色切换** 代替登录；权限与脱敏按角色即时过滤

## 演练剧本（建议按序）

### 1. 专职心理教师 · 工单与档案

1. 右上角选 **专职心理教师 · 林晓雯**
2. 打开 **预警工单** → 进入橙色单 `TK-20261101-001`（王浩然）
3. 填写处理说明 → **提交处理**；可试 **关闭工单** / **手动升级**
4. 打开 **一人一档** → 点王浩然详情，确认可见 **橙** 色风险与成因摘要、时间线
5. 打开 **校级台账** / **班级波动**（高一（3）班）查看只读看板

### 2. 班主任 · 脱敏差异

1. 切换 **班主任 · 陈志强**
2. **一人一档** 仅本班；列表与详情 **无风险颜色、无成因摘要**
3. **预警工单** 可见黄单（李思琪、孙嘉怡）；点开处理
4. **班级波动** 有人数/行为/工单数，**无** 风险颜色分布

### 3. 家长 · 建议书签收

1. 切换 **家长 · 王秀兰**
2. 进入 **家校建议书**，查看王浩然 / 王雨桐的脱敏文本
3. 对未签收项点 **确认签收**（状态变为已签收）

### 4. 区心理中心 · 态势

1. 切换 **区心理中心 · 周明远**
2. **区级看板** 查看学校/学生/风险分布与逾期工单
3. **校级台账** 可切换学校；处理红色升级工单 `TK-20261101-003`

### 5. 学生 · 测评入口

1. 切换 **学生 · 王浩然**
2. **学生测评/求助** → 提交任意量表类型 → 仅提示成功，**不返回分数**
3. 发送求助 → 仅确认收到，**不自动建工单**

## 种子数据摘要

- 2 所学校（东城区第一中学、东城区实验小学），4 个班级
- 8 名学生、若干关注档案
- 5 张预警工单（黄/橙/红，含 pending / processing / overdue / escalated / closed）
- 家校建议书、行为观察、应激事件、量表 mock 结果

数据在浏览器内存中，刷新页面会恢复为初始种子。

---

## 已知限制（演练版）

- 无真实账号登录、会话、RBAC 服务端鉴权
- 无持久化；刷新丢失操作结果
- 无真实量表计分 / 测谎 / 常模；不返回分数与 `risk_flag`
- 未实现教育局管理员、学校领导、科任教师全量路径（可按文档后续扩展）
- 工单逾期扫描、加密 `raw_data`、预约排班等未做
- 桌面优先，移动端仅保证可读
